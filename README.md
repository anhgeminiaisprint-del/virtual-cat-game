# 🐾 Mochi Cat - Virtual Pet Game

Trò chơi nuôi mèo ảo (Virtual Cat Pet Game) với giao diện dễ thương, hiện đại và sinh động chạy hoàn toàn trên trình duyệt bằng HTML5, CSS3/Tailwind CSS và Vanilla JavaScript.

## ✨ Tính năng chính
- **Nhân vật mèo SVG sinh động**: Tự động thay đổi biểu cảm (vui vẻ, đói, buồn ngủ, đang ăn, được vuốt ve), chuyển động chớp mắt, ngoe nguẩy đuôi.
- **3 Chỉ số thời gian thực**: Độ no (Hunger), Độ vui vẻ (Happiness), Năng lượng (Energy).
- **Tương tác**: Cho ăn (Feed), Chơi đùa (Play mini-game bắt cuộn len), Vuốt ve (Pet), Đi ngủ (Sleep & Night mode).
- **Tùy biến & Tủ đồ**: Đổi tên mèo, chọn màu lông (Vàng Cam, Trắng Tuyết, Tuxedo, Tam Thể, Sakura Hồng) và phụ kiện (Nơ đỏ, Mũ tiệc, Vương miện, Mũ đầu bếp, Kính râm).
- **Âm thanh tổng hợp**: Sử dụng Web Audio API (không cần tải file ngoài).
- **Lưu trữ tự động**: Tích hợp LocalStorage.
